# NATIONAL_MAP_DASHBOARD — 카드 3: 전국 지도 기반 현황

> 기준 v10.0 · 2026-11-14 · 상태: 서버 요약의 `national`과 전국 알림, 모의 서버, 카드(`UI/Dashboard/NationalDashboardCard.cs`), 축약 지도(`NationalMapPreview.cs`) 구현. 상세 지도는 기존 전국 지도 화면. 서버와 규칙은 테스트함. Unity 화면은 컴파일 검사만 함

[LIVE_DASHBOARD](LIVE_DASHBOARD.md)의 세 번째 카드입니다. 대한민국 시·군·구 지도 위에 전국이 지금 얼마나 안전한지 보여 줍니다.

## 1. 방향

- **지도 데이터를 새로 들이지 않았습니다.** 게임에 이미 있는 대한민국 시·군·구 경계(`kr_regions.json`, 230곳)를 축약 지도와 상세 지도가 함께 씁니다. 출처와 이용 조건은 5장.
- 지도의 지역 코드가 곧 게임의 도시 코드입니다. 도시별 위험도는 v8.0의 도시 위험도, 순위는 지역 랭킹, 지원 요청은 도시 간 지원에서 옵니다.
- 카드에는 **축약 지도**(확대·축소 없음), 상세 보기에는 **확대·축소하는 전체 지도**.

## 2. 카드

펼친 카드 (높이 330):

```
┌────────────────────────────────────┐
│▌ 전국 현황                          │
│────────────────────────────────────│
│  ┌─────────┐  급한 도시              │
│  │ (축약    │  ■ 해운대구  91         │
│  │  지도)   │  ■ 종로구  88           │
│  │    ○    │  ◆ 수원시  74           │
│  └─────────┘                        │
│  지도 경계: 통계청 SGIS · vuski/…     │
│  전국 평균 안전도               81   │
│  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔                  │
│  긴급 도시                  ■ 2곳   │
│  우리 도시 순위           12위 / 230 │
│  1위 도시              종로구  940점 │
│  지원 요청                    3곳   │
│  ● 실시간 · 14:03:21 갱신  Shift+F9 상세 │
└────────────────────────────────────┘
```

| 지시서 4장의 표시 항목 | 카드에서 | 출처 (`national`의 항목) |
|---|---|---|
| 도시별 위험도 | 축약 지도의 색 (3장) | 기존 도시 위험도 서비스 (`GET /cities/risk`) |
| 전국 평균 안전도 | `81` + 막대 | `average_safety` = 100 − 모든 도시 위험도의 평균 |
| 긴급 도시 수 | `■ 2곳` (붉음) / `없음` | `emergency_cities` |
| 도시별 랭킹 | `1위 도시  종로구  940점` — 5위까지는 상세 보기에서 | `top` (상위 5곳: 순위, 점수, 위험도, 단계) |
| 우리 도시 순위 | `12위 / 230` (이방인은 `—`) | `home_rank`, `total_cities` |
| 지역 지원 요청 | `3곳` / `없음` | `support_requests` — 지원을 요청한 도시의 수 |
| (급한 도시) | 지도 옆에 4곳까지: 단계 표시 + 이름 + 위험도 | `urgent` (긴급 단계이거나 침공 중인 도시 5곳까지. 긴급 단계가 먼저, 그 안에서는 위험도가 높은 순) |

접힌 카드: `● 안전도 81`. 긴급 도시가 있으면 `■ 긴급 2곳`. 카드의 왼쪽 띠는 전국에서 가장 나쁜 단계의 색입니다 (긴급 도시가 있으면 긴급, 없고 위험 도시가 있으면 위험, 아니면 안전).

요약에는 그 밖에 `danger_cities`(위험 단계의 도시 수)와 `invasion_cities`(침공 중인 도시 수)가 있고, 지도를 열 수 없을 때의 글 화면(4장)에서 씁니다.

## 3. 축약 지도

`NationalMapPreview` (112×104, 배율에 따라 커짐).

- 시·군·구 230곳을 **위험 단계의 색**으로 칠합니다. 이웃한 지역은 밝기를 조금씩 달리해 경계가 보입니다 (큰 지도와 같은 방법). 위험도를 아직 받지 못한 동안에는 회색입니다.
- **우리 도시는 흰 점**, **급한 도시는 붉은 네모**(5곳까지)로 표시합니다. 작은 지도에서는 색만으로 구분하기 어려워서, 급한 도시는 옆의 목록에 모양(`■` `◆`)과 이름, 숫자로 다시 적습니다.
- 확대·축소, 끌기, 누르기는 없습니다 (그것은 상세 보기에서).
- 색은 전국 지도 화면이 쓰는 `CityRiskService`의 값입니다. 축약 지도가 따로 서버에 묻지 않고, 요약이 올 때 그 서비스의 값이 오래됐으면 그쪽이 다시 받습니다. 도형도 전국 지도의 그리기 함수(`MapPanel.AddRegion`)를 같이 씁니다.
- 꼭짓점이 많아서(23,076개) **자기 캔버스**에 따로 둡니다. 위험도가 바뀔 때만 다시 그리고, 카드의 글자가 바뀌어도 지도는 다시 묶이지 않습니다.
- 지도 데이터가 없으면 "지도 데이터 없음"이라고 적고 나머지 카드는 그대로 동작합니다.
- 지도 바로 아래에 **출처**를 적습니다: `지도 경계: 통계청 SGIS · vuski/admdongkor (CC BY 4.0)` (5장).

## 4. 상세 보기: 전체 지도

`Shift` + `F9`, 또는 왼쪽 Alt 를 누른 채 카드의 몸통을 누릅니다.

**기존 전국 지도 화면**을 엽니다 (M 키로 여는 지도와 같은 화면, [MAP_SYSTEM](MAP_SYSTEM.md) 3장). 새 지도 화면을 만들지 않았습니다.

| 기능 | 내용 |
|---|---|
| 확대·축소 | 마우스 휠 |
| 이동 | 끌기 |
| 시·도 → 시·군·구 | 눌러서 들어가고, 오른쪽 버튼이나 Esc 로 뒤로 |
| 도시별 위험도 | 위험도 보기가 켜진 채로 열림: 시·군·구가 단계의 색으로, 단계 표시(모양)와 함께 |
| 도시 정보 | 시·군·구를 누르면 위험도, 방어력, 순위, 침공, 위험도 이력 |
| 랭킹, 지원 요청 | 지도 화면의 목록 (v8.0) |
| 출처 | 지도 화면 아래에 전체 문구가 늘 보임 |

지도를 열 수 없는 곳(지도가 아직 열리지 않은 튜토리얼 단계 등)에서는 같은 내용을 **글로** 보여 줍니다: 평균 안전도, 긴급·위험·침공 도시 수, 우리 도시 순위, 지원 요청, 지역 순위 5위까지, 급한 도시 목록. 전투 중에는 상세 보기 자체가 열리지 않습니다.

## 5. 행정구역 경계 데이터의 출처와 라이선스

지시서 4장: "행정구역 경계 데이터는 정식 사용 가능한 출처를 활용하고 라이선스를 확인합니다."

v10.0에서 새로 받은 데이터는 없습니다. Phase 2 에서 들인 경계 데이터를 그대로 씁니다. 그때 확인한 내용은 [MAP_SYSTEM](MAP_SYSTEM.md) 2.1에 있고, 요점은 이렇습니다.

| 항목 | 내용 |
|---|---|
| 원천 | 통계청 통계지리정보서비스(SGIS)의 행정동 경계 |
| 원천의 이용 조건 | **공공누리 제1유형** (출처표시). 상업적 이용과 변형 가능 |
| 가공본 | [vuski/admdongkor](https://github.com/vuski/admdongkor)의 `ver20261001` (고정한 커밋과 SHA-256 은 MAP_SYSTEM 2.1) |
| 가공본의 이용 조건 | **CC BY 4.0**. 출처를 표시하고 고친 사실을 밝히면 상업적 이용과 변형 가능 |
| 이 게임에서 고친 것 | 행정동을 시·군·구로 합치고 단순화 (점의 6%), 작은 섬 제외 ([MAP_SYSTEM](MAP_SYSTEM.md) 2.2) |
| 결과 | 시·도 16, 시·군·구 230, 점 23,076개 |

**출처 표시 의무를 지키는 방법:**

- 상세 지도(전체 지도 화면) 아래에 전체 문구가 늘 보입니다 (기존).
- **축약 지도 아래에도 짧은 출처를 적었습니다** (새로 더함). 카드가 좁아 전체 문구가 들어가지 않아 원천과 가공본의 이름, 가공본의 라이선스를 적고, 전체 문구는 상세 보기의 지도에 있습니다.
- 카드를 접거나 숨기면 지도도 보이지 않으므로 출처도 함께 사라집니다.

**확인의 한계:** 이용 조건은 2026-11-13에 저장소의 라이선스 문서를 읽어 확인한 것이고 v10.0에서 다시 읽지는 않았습니다 (이 작업 중에는 외부에 접속하지 않음). **법률 검토를 받은 것이 아니므로** 상용 출시 전에 [SECURITY_POLICY](SECURITY_POLICY.md) 9장의 검토 목록에 따라 다시 확인해야 합니다. 축약 지도의 **짧은 출처 표기가 조건을 채우는지**도 그때 함께 확인해야 합니다 (모자라면 카드에 "ⓘ 출처"를 두고 전체 문구를 띄우는 방법이 있습니다).

## 6. 지도 데이터와 게임 도시 데이터의 연결

| 것 | 연결 |
|---|---|
| 지도의 지역 | `kr_regions.json`의 시·군·구 코드 5자리 (합친 시는 앞 4자리 + `0`) |
| 게임의 도시 | 같은 코드 (`regions.code`, 요약의 `region_code`) |
| 축약 지도의 색 | 코드로 `CityRiskService.Of(code)`를 찾아 단계의 색 |
| 우리 도시 표시 | `my_city.region_code` → 지도의 그 지역의 이름표 자리 |
| 급한 도시 표시 | `national.urgent[].region_code` → 〃 |
| 이름 | 서버가 `name`으로 보냄 (지역 테이블의 이름). 모르는 코드는 코드를 그대로 |

서버의 지역 목록(`0004_seed_regions.sql`)은 클라이언트의 지역 목록(`KrRegions`)에서 뽑아 만든 것이라 지도 파일의 지역과 같습니다. **운영 홈페이지의 지역 목록(229곳)과 코드가 같은지는 아직 확인하지 못했습니다** ([MAP_SYSTEM](MAP_SYSTEM.md) 2.3). 다르면 대응표가 필요하고, 그때까지 지도에 없는 코드의 도시는 색칠되지 않고 목록에만 나옵니다.

## 7. 전국 알림과 갱신

- 다른 도시의 급한 일은 요약의 알림(`national_emergency`, `national_invasion`)으로 옵니다. 얼마나 보낼지는 관리자의 **전국 긴급 알림 표시 정책**이 정합니다: 표시 안 함 / 긴급 단계인 도시(기본) / 긴급 단계이거나 침공 중인 도시. 한 번에 3곳까지(1~10), 위험도가 높은 순.
- 긴급 단계 알림은 **전투 중이 아닐 때만** 한 줄 알림으로 뜹니다. 침공 알림은 띄우지 않고 카드에서 봅니다 ([LIVE_DASHBOARD](LIVE_DASHBOARD.md) 6장).
- 우리 도시는 전국 알림에서 빠집니다 (우리 도시 카드가 알림).

| 지시서 7장 | 한 것 |
|---|---|
| 도시 위험도 변경 | 주기 갱신 (기본 20초). 내 전투 결과가 반영되면 곧 |
| 긴급 침공 | 주기 갱신 + 알림 |
| 지역 순위 변경 | 주기 갱신 |

전국의 값은 다른 사람들의 활동으로 바뀌므로 대부분 주기 갱신으로 받습니다.
