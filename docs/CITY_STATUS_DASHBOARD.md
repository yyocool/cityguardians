# CITY_STATUS_DASHBOARD — 카드 2: 우리 도시 현황

> 기준 v10.0 · 2026-11-14 · 상태: 서버 요약의 `my_city`와 알림, 모의 서버, 카드(`UI/Dashboard/CityDashboardCard.cs`), 상세 보기 구현. 서버와 규칙은 테스트함. Unity 화면은 컴파일 검사만 함

[LIVE_DASHBOARD](LIVE_DASHBOARD.md)의 두 번째 카드입니다. 내가 전입신고한 도시가 지금 어떤지 보여 줍니다.

## 1. 방향

- 값은 모두 **이미 있는 시스템이 계산한 것**입니다. 위험도·단계·방어력·침공·순위는 도시 위험도([CITY_RISK_SYSTEM](CITY_RISK_SYSTEM.md)), 유효 전입자와 성장 단계는 도시 성장([CITY_GROWTH_SYSTEM](CITY_GROWTH_SYSTEM.md)), 재정은 도시 재정([CITY_TREASURY_SYSTEM](CITY_TREASURY_SYSTEM.md))에서 옵니다. 대시보드가 따로 세는 것은 없습니다.
- 위험도는 서버만 계산합니다. 카드는 보여 줄 뿐이고, **경고를 띄울지도 서버가 판정**합니다.
- 급한 일은 접혀 있어도, 전투 중에도 보입니다.

## 2. 카드

펼친 카드 (높이 270). 머리 줄 오른쪽에 도시 이름.

| 줄 | 값 | 출처 (`my_city`의 항목) |
|---|---|---|
| 위험도 | `42  ▲ 주의` + 단계 색의 막대 | `risk`, `stage` — `GET /cities/risk`와 같은 값 |
| 방어력 | `1,240` | `defense_power` |
| 유효 전입자 | `0명` | `valid_residents` — `GET /cities/{code}/growth`와 같은 값 |
| 도시 재정 | `3,500 GC` | `treasury_gc` — 일반 회계 + 예비비 (`GET /cities/{code}/treasury`의 합) |
| 침공 | `침공 없음` / `■ 외곽 침공  3 / 10` (붉음) | `invasion_kind`, `invasion_progress`, `invasion_required` |
| 내 기여도 | `85` | `my_contribution` — 이 도시에 쌓은 내 기여 포인트 (`region_contributions`. 방어전·FPS 를 이기면 쌓임) |
| (경고 줄) | `● 지금은 경고가 없어요` / 붉은 띠에 경고 문구 | `alert`, `alert_reason` |

접힌 카드: `위험도 42  ▲ 주의`. 침공 중이면 `■ 외곽 침공 · 위험도 42`. 한 줄로 줄어든 화면에서는 `▲ 42` / `■ 침공`.

- **유효 전입자**는 v9.0의 규칙으로 셉니다. 기본 규칙은 연결된 계정만 세는데 계정 연결 기능이 아직 없어, 지금은 어느 도시나 0명입니다 ([CITY_GROWTH_SYSTEM](CITY_GROWTH_SYSTEM.md) 2장).
- **도시 재정**은 게임 안의 GC 입니다. 실제 돈이 아니고 CITY PASS · 장학의 예산과 섞이지 않습니다. 지방세가 꺼져 있으면 0 에서 움직이지 않습니다.
- **이방인**(전입신고 전)에게는 줄 대신 "아직 전입신고를 하지 않았어요. 전입신고를 하면 우리 도시의 현황이 여기에 보여요."가 보이고, 접힌 카드에는 "전입신고 전"이 보입니다. 서버는 `resident: false`와 빈 값을 보냅니다.

## 3. 위험 단계의 색과 경고

단계는 색과 함께 **모양과 글자**로 보입니다 (지도와 같은 표시).

| 단계 | 표시 | 카드 |
|---|---|---|
| 안전 | `● 안전` | 왼쪽 띠와 막대가 단계의 색 |
| 주의 | `▲ 주의` | 〃 |
| 위험 | `◆ 위험` | 〃 |
| 긴급 | `■ 긴급` | 〃 + 경고 |

경고 (`alert`)는 서버가 정합니다. 까닭(`alert_reason`)은 급한 순서대로 하나입니다.

| 까닭 | 때 | 카드의 경고 줄 | 카드의 모습 |
|---|---|---|---|
| `invasion` | 우리 도시에 침공이 진행 중 | `■ 외곽 침공! 도시를 지켜 주세요` | **붉은빛 + 띠가 깜박임**, 접힌 머리 줄에 침공 |
| `emergency` | 긴급 단계 | `■ 긴급 단계예요. 도시를 지켜 주세요` | 붉은빛 + 띠가 깜박임 |
| `risk` | 위험도가 관리자가 정한 **도시 위험 경고 기준** 이상 (기본 70) | `◆ 위험도가 높아요` | 색만 바뀜 (깜박이지 않음) |

- 기준은 관리자 화면에서 바꿉니다 ([LIVE_DASHBOARD](LIVE_DASHBOARD.md) 7장). 클라이언트는 기준과 비교하지 않고 서버의 `alert`를 그대로 씁니다.
- 같은 내용이 알림으로도 옵니다 (`city_invasion`, `city_emergency`, `city_risk`). 침공은 침공마다 한 번, 나머지는 하루에 한 번 한 줄 알림으로 뜹니다. **전투 중에도 뜹니다** ([LIVE_DASHBOARD](LIVE_DASHBOARD.md) 6장).
- 대시보드를 통째로 숨겨 두었어도, 긴급 알림이 있으면 작은 붉은 표시가 남습니다.
- 위험도가 높아도 플레이어의 GC, 은행 잔액, 게임 안의 신용에는 아무 일도 일어나지 않습니다 (v8.0의 규칙 그대로. 이 카드는 지갑을 건드리지 않음).

## 4. 상세 보기

`Shift` + `F8`, 또는 왼쪽 Alt 를 누른 채 카드의 몸통을 누릅니다. 메뉴의 제목은 "{도시 이름} 현황"이고 다섯 가지가 있습니다. 모두 **이미 있는 화면**을 엽니다.

| 메뉴 (지시서 3장의 항목) | 여는 화면 | 값의 출처 |
|---|---|---|
| 도시 방어 현황 | v8.0의 도시 화면 (`CityActions.Open`): 방어 시설, 침공, 내 기여도, 시설 복구, 도시 기금 | `GET /cities/{code}` 등 |
| 도시 재정과 지방세 (도시 재정 · 지방세) | v9.0의 "도시 살림" (`CityOpsActions.Open`): 지방세 정책, 재정, 집행 내역, 참여예산 | `GET /cities/{code}/treasury` 등 |
| 성장 단계와 상징거리 (도시 성장 단계 · 상징거리 모델링 현황) | 작은 창: 유효 전입자, 성장 단계, 모델링 상태 (`제작 전` → `기획 중` → `제작 중` → `검수 중` → `개방 준비 완료` → `개방됨`) | 요약의 `growth_stage`, `growth_stage_name`, `modeling_status` |
| 지역 순위 | v8.0의 랭킹 화면 (`CityActions.OpenRankings`) | `GET /cities/rankings` |
| 긴급 지원 요청 | v8.0의 지원 화면 (`CityActions.OpenSupport`): 도움을 청한 도시, 지원 출동 | `GET /cities/support` |

- 메뉴의 항목 옆에 지금 값이 보입니다 (방어력, 재정, 단계, 순위, "요청 중").
- 이방인이 열면 "전입신고를 하면 우리 도시의 현황을 볼 수 있어요"가 뜹니다.
- 전투 중에는 열리지 않습니다. 열린 화면에서 뒤로 가면 이 메뉴로 돌아옵니다.

## 5. 갱신

| 지시서 7장 | 한 것 |
|---|---|
| 위험도 변경 | 내 전투 결과가 도시에 반영되면 (`CityEffectApplied`) 곧 다시 받음. 다른 사람이 바꾼 것은 다음 주기에 |
| 침공 이벤트 | 침공의 시작과 끝은 서버의 예약 작업이 정함 → 다음 주기(기본 20초)에 카드와 알림으로 |
| 도시 재정 변경 | 내가 낸 세금·기금은 내 GC 가 달라지므로 곧 다시 받음. 다른 사람의 것은 다음 주기에 |
| 전입자 수 변경 | 내 전입·이사는 곧, 다른 사람의 것은 다음 주기에 |
