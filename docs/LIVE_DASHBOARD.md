# LIVE_DASHBOARD — 실시간 3종 대시보드

> 기준 v10.0 · 2026-11-14 · 상태: 서버(`GET /dashboard/summary`, 관리자 설정), 규칙(`Domain/Dashboard.cs`), 모의 서버, 클라이언트 화면(`UI/Dashboard`) 구현. 서버와 규칙은 테스트했고 서버는 로컬에 띄워 HTTP 로 확인함. **Unity 화면은 컴파일 검사만 했고 실행해 보지 못함** (카드의 모양·크기·움직임을 눈으로 확인하지 못함)

## 1. 방향

게임 화면 오른쪽에 카드 세 장을 세로로 놓습니다. 걸어 다니면서 **내 돈, 우리 도시, 전국**이 지금 어떤지 한눈에 봅니다.

| # | 카드 | 한 줄 설명 | 문서 |
|---|---|---|---|
| 1 | 내 계좌 및 투자현황 | 보유 GC, 은행 예금, 가상 주식, 대출, 순자산 | [FINANCE_DASHBOARD](FINANCE_DASHBOARD.md) |
| 2 | 우리 도시 현황 | 위험도, 방어력, 전입자, 재정, 침공, 내 기여도 | [CITY_STATUS_DASHBOARD](CITY_STATUS_DASHBOARD.md) |
| 3 | 전국 지도 현황 | 축약 지도, 평균 안전도, 긴급 도시, 순위, 지원 요청 | [NATIONAL_MAP_DASHBOARD](NATIONAL_MAP_DASHBOARD.md) |

지키는 것:

- **새로 계산하지 않습니다.** 카드의 값은 지갑, 도시 위험도, 지역 랭킹, 전입자 집계, 도시 재정이 이미 내놓는 값입니다. 서버의 요약은 그것을 한 번에 모아 줄 뿐이고, 클라이언트는 받은 값을 글자로 옮기기만 합니다 (금액을 더하거나 빼서 새 값을 만들지 않습니다. 순자산도 서버가 준 값입니다).
- **읽기만 합니다.** 대시보드에서 돈이 움직이거나 위험도가 바뀌는 일은 없습니다. 맡기기·찾기는 은행에서, 기여는 작전 본부에서 합니다.
- **금융 정보는 본인의 것만.** 요약에는 다른 사람을 고르는 인자가 없습니다 (7장, [API_SPEC](API_SPEC.md) 23장).
- **없는 것을 있다고 하지 않습니다.** 서버에 아직 없는 금융 기능은 "준비 중"으로, 관리자가 허용했을 때만 "개발용 샘플"이라는 표시와 함께 보입니다.
- **시야가 먼저입니다.** 카드의 폭은 화면의 24%를 넘지 않고, 전투에서는 스스로 접힙니다. 다만 우리 도시의 급한 일은 접혀 있어도 보입니다.

## 2. 카드의 상태

카드마다 따로 세 가지 상태를 가집니다 (지시서 5장).

| 상태 | 코드 | 모습 |
|---|---|---|
| 펼침 | `expanded` | 머리 줄 + 값들 + 연결 상태 줄 |
| 접힘 | `collapsed` | 머리 줄만. **핵심 수치 하나는 남음** |
| 숨김 | `hidden` | 보이지 않고 자리도 차지하지 않음 |

접힌 카드에 남는 수:

| 카드 | 접혔을 때 |
|---|---|
| 내 계좌 | `순자산 12,340 GC` |
| 우리 도시 | `위험도 42  ▲ 주의` — 침공 중이면 `■ 외곽 침공 · 위험도 42` (침공이 먼저) |
| 전국 현황 | `● 안전도 81` — 긴급 도시가 있으면 `■ 긴급 2곳` |

상태가 정해지는 순서 (`DashboardState.StateOf`):

1. 대시보드 전체를 숨겼으면 (F6) 모두 숨김.
2. 이번 전투 중에 이용자가 손댄 카드는 그 선택.
3. 이용자가 숨긴 카드는 어느 모드에서도 숨김.
4. 전투 모드의 규칙 (4장).
5. 이용자가 정한 상태. 손댄 적이 없으면 **관리자가 정한 기본값** (7장. 기본: 계좌 펼침, 우리 도시 펼침, 전국 접힘).

자리가 모자라면 펼친 카드가 화면에서만 접혀 보일 수 있습니다 ([HUD_LAYOUT_SYSTEM](HUD_LAYOUT_SYSTEM.md) 3장). 그때에도 이용자의 설정은 바뀌지 않습니다.

대시보드는 GC 표시와 같은 때(첫 보상을 받은 뒤)에 나타납니다. 그 전의 튜토리얼 화면에는 없습니다.

## 3. 구조

지시서 8장의 이름 그대로입니다. 화면(UI)과 데이터 처리가 다른 어셈블리에 있고, 규칙은 Unity 없이 테스트합니다.

| 컴포넌트 | 자리 | 하는 일 |
|---|---|---|
| `LiveDashboardController` | `Gameplay/Dashboard` | 지휘자. `GameRoot`에 붙어 장면이 바뀌어도 남음. 접속한 사람에 맞춰 데이터 서비스를 잇고, 전투 모드를 상태에 알리고, 키를 상태로 옮기고, 설정을 저장. **그리지 않음** |
| `DashboardActions` | `Gameplay/Dashboard` | 상세 보기와 대시보드 설정. 이미 있는 화면을 엶 (5장) |
| `DashboardLayoutManager` | `UI/Dashboard` | 카드 세 장을 화면에 놓음. 다른 HUD 가 쓰는 자리를 재고, 마우스 조작을 받음 |
| `DashboardCardBase` | `UI/Dashboard` | 카드의 공통 틀: 유리판, 테두리, 머리 줄, 줄(row) 재사용, 연결 상태 줄 |
| `FinanceDashboardCard`, `CityDashboardCard`, `NationalDashboardCard` | `UI/Dashboard` | 카드별 몸통 |
| `NationalMapPreview` | `UI/Dashboard` | 전국 카드 안의 축약 지도 |
| `DashboardStyle` | `UI/Dashboard` | 디자인 시스템: 색, 둥근 모서리, 그림자 |
| `DashboardDataService` | `Services` | 요약을 정해진 간격으로 받음. 연결 상태와 마지막 갱신 시각 |
| `DashboardNotificationService` | `Services` | 같은 알림을 한 번만 알림 |
| `DashboardPreferenceService` | `Services` | 이용자의 설정을 기기에 저장 |
| `DashboardViews` | `Services` | 요약을 카드의 줄(이름·값·꼬리표)로 바꿈 |
| `DashboardAnimationController` | `Domain` | 카드 한 장의 움직임 (자리, 크기, 투명도). Unity 없이 테스트 |
| `DashboardState`, `DashboardLayout`, `DashboardRefreshPolicy`, `DashboardFormat` | `Domain/Dashboard.cs` | 상태, 자리 잡기, 갱신 간격, 글자 규칙 |

기존 서비스와 겹치는 처리는 만들지 않았습니다.

- 축약 지도의 색은 전국 지도가 쓰는 `CityRiskService`의 값을 그대로 씁니다. 지도 모양도 전국 지도의 `MapPanel.AddRegion`을 같이 씁니다.
- 은행 계좌와 거래 내역은 `BankActions`의 글을, 도시 화면은 `CityActions` / `CityOpsActions`를 그대로 엽니다.
- 서버의 요약은 `CityService::board()` 한 번으로 위험도·랭킹·침공을 얻습니다 (도시 화면이 쓰는 것과 같은 계산).

## 4. 전투 모드 연동

`CombatService.ActiveMode`를 보고 정합니다 (지시서 6장).

| 모드 | 카드 | 까닭 |
|---|---|---|
| 방, 도시, **사냥(헌트)** | 이용자가 정한 대로 | 기본 대시보드 |
| **FPS** | 세 장 모두 접힘 | 전투 시야가 먼저. 머리 줄 세 개만 남음 |
| **타워디펜스** (혼자, 협동) | 기본은 세 장 모두 접힘. 이용자가 고르면 오른쪽에 그대로 / 왼쪽으로 옮기기 | 오른쪽 위는 전술 미니맵과 웨이브 정보의 자리 |

- **전투가 끝나면 이전 상태로 돌아갑니다.** 전투 모드는 이용자의 설정을 건드리지 않고 그 위에 덮어 보이기만 하므로, 모드가 끝나면 저절로 원래대로입니다.
- 전투 중에 카드를 펴거나 숨긴 것은 **그 전투 동안만** 지켜지고 저장되지 않습니다. 대시보드 전체 숨기기(F6)만은 언제 눌러도 설정으로 남습니다.
- 타워디펜스에서의 자리는 대시보드 설정(Shift+F6)에서 고릅니다: 오른쪽에 접어 두기(기본) → 오른쪽에 그대로 → 왼쪽으로 옮기기.
- 미니맵, 웨이브 표시, 탄약 표시처럼 전투 화면이 쓰는 자리는 재서 피합니다. 자리가 모자라면 카드가 더 접히거나 한 줄로 줄어듭니다 ([HUD_LAYOUT_SYSTEM](HUD_LAYOUT_SYSTEM.md) 3장).
- 상세 보기와 설정은 전투 중에 열리지 않습니다 ("전투가 끝나면 자세히 볼 수 있어요").

**전투 중에도 도시의 급한 일은 보입니다.**

- 접힌 우리 도시 카드의 머리 줄이 침공을 먼저 알리고 (`■ 외곽 침공 · 위험도 42`), 카드가 붉은빛을 띠고 왼쪽 띠가 깜박입니다.
- 우리 도시의 경고·긴급 알림은 전투 중에도 한 줄 알림으로 뜹니다. 다른 도시의 알림은 전투 중에는 띄우지 않습니다 (6장).
- 대시보드 전체를 숨겨 두었어도, 우리 도시에 급한 일이 생기면 카드가 있던 자리의 맨 위에 작은 붉은 표시(`■ 우리 도시에 외곽 침공!   F6 보기`)가 나옵니다.

## 5. 데이터 갱신과 상세 보기

### 갱신

카드 세 장은 `GET /dashboard/summary` **한 번**으로 값을 받습니다 ([API_SPEC](API_SPEC.md) 23장). 매 프레임 묻지 않습니다 (`DashboardRefreshPolicy`).

| 때 | 동작 |
|---|---|
| 평소 | 관리자가 정한 간격마다 한 번 (기본 20초, 5~300초) |
| 값이 바뀌는 일이 있었을 때 | 0.3초 뒤에 한 번 더. 다만 요청 사이를 **2초보다 좁히지 않음** |
| 실패 | 간격을 두 배씩 늘림 (최대 2분). 성공하면 원래 간격으로 |
| 요청이 나가 있는 동안 | 또 보내지 않음 |

"값이 바뀌는 일" (지시서 7장의 갱신 조건):

| 조건 | 신호 |
|---|---|
| 금융 거래 완료 | 내 보유 GC, 통장, 정기예금 가운데 하나가 달라짐 (`GameSession.Changed`. 경험치처럼 상관없는 변화로는 묻지 않음) |
| 전투 결과 (위험도, 침공 진행, 기여도) | `GameSession.CityEffectApplied` |
| 전입신고, 이사 | 내 소속 도시가 달라짐 |
| 전투 모드에 들어가고 나올 때 | 모드 변경 |
| 다른 사람이 바꾼 것 (전입자 수, 재정, 다른 도시의 위험도, 순위, 침공 시작) | 주기 갱신으로 받음 |

실시간으로 밀어 주는 길(WebSocket)은 쓰지 않았습니다. v9.0의 실시간 서버는 협동 방어전의 방에만 있고 로비 전체에 알리는 통로가 없어서, 지금은 "일이 있으면 곧 다시 묻고, 없으면 20초마다 묻는" 방식입니다 (10장).

카드 아래의 한 줄이 연결 상태를 알립니다. 색에 기대지 않도록 모양과 글자를 함께 씁니다.

| 상태 | 표시 |
|---|---|
| 받는 중 | `… 불러오는 중` |
| 정상 | `● 실시간 · 14:03:21 갱신` |
| 끊김 | `▲ 연결 끊김 · 마지막 갱신 14:03:21 (2분 전)` — 카드에는 마지막으로 받은 값이 그대로 남음 |

### 상세 보기

상세 화면을 새로 만들지 않고 **이미 있는 화면**을 엽니다. 그 화면들이 저마다의 기존 API 로 값을 받습니다.

| 카드 | 상세 보기 (Shift+카드 키, 또는 Alt 를 누른 채 카드 몸통 누르기) |
|---|---|
| 내 계좌 | 메뉴 6개: 은행 계좌, 예금 거래 내역, 주식 보유 종목, 주식 거래 내역, 대출 상환 일정, 자산 변동 그래프 ([FINANCE_DASHBOARD](FINANCE_DASHBOARD.md) 4장) |
| 우리 도시 | 메뉴 5개: 도시 방어 현황, 도시 재정과 지방세, 성장 단계와 상징거리, 지역 순위, 긴급 지원 요청 ([CITY_STATUS_DASHBOARD](CITY_STATUS_DASHBOARD.md) 4장) |
| 전국 현황 | 확대·축소하는 전국 지도 (M 키의 지도와 같은 화면, 위험도 보기) ([NATIONAL_MAP_DASHBOARD](NATIONAL_MAP_DASHBOARD.md) 4장) |

## 6. 알림

요약의 `notifications`에 서버가 만든 알림이 옵니다. 알림마다 `id`가 있어 **같은 일은 한 번만** 알립니다 (침공은 침공마다, 단계와 위험도 경고는 하루에 한 번).

| 종류 | 단계 | 생기는 때 | 한 줄 알림 |
|---|---|---|---|
| `city_invasion` | 긴급 | 우리 도시에 침공 | 언제나 (전투 중에도) |
| `city_emergency` | 긴급 | 우리 도시가 긴급 단계 | 언제나 |
| `city_risk` | 경고 | 우리 도시의 위험도가 관리자가 정한 기준 이상 (기본 70) | 언제나 |
| `city_support` | 안내 | 우리 도시가 지원을 요청함 | 띄우지 않음 (카드에서 봄) |
| `national_emergency` | 경고 | 다른 도시가 긴급 단계 | 전투 중이 아닐 때만 |
| `national_invasion` | 안내 | 다른 도시에 침공 (정책이 2일 때만 옴) | 띄우지 않음 (카드에서 봄) |

- 요약 한 번에 한 줄 알림은 **둘까지**이고 우리 도시의 것이 먼저입니다. 나머지는 카드에서 봅니다.
- 다른 도시의 알림을 얼마나 보낼지는 관리자의 "전국 긴급 알림 표시 정책"이 정합니다 (7장).
- 우리 도시 카드의 경고(`alert`)와 그 까닭(`invasion` / `emergency` / `risk`)은 **서버가 판정**합니다. 클라이언트는 기준과 비교하지 않습니다.
- 알림은 한 줄 알림과 카드의 표시뿐입니다. 소리, 휴대전화 알림, 기록 화면은 없습니다 (10장).

## 7. 관리자 설정

관리자 화면 "실시간 대시보드 설정" (`/admin/dashboard`). 설명은 [ADMIN_SYSTEM](ADMIN_SYSTEM.md) 13장.

| 항목 | 값 | 기본 |
|---|---|---|
| 카드별 기본 표시 여부 (3개) | 표시 / 숨김 | 모두 표시 |
| 카드별 기본 펼침 상태 (3개) | 펼침 / 접힘 | 계좌 펼침, 우리 도시 펼침, 전국 접힘 |
| 데이터 갱신 간격 | 5 ~ 300초 | 20초 |
| 도시 위험 경고 기준 | 위험도 0 ~ 100 | 70 |
| 전국 긴급 알림 표시 정책 | 표시 안 함 / 긴급 단계인 도시 / 긴급 단계이거나 침공 중인 도시 | 긴급 단계인 도시 |
| 한 번에 알리는 다른 도시의 수 | 1 ~ 10 | 3 |
| 준비되지 않은 금융 항목 | "준비 중"으로 표시 / "개발용 샘플"로 표시 | "준비 중" |

- 표시와 펼침은 **처음 보는 이용자의 기본값**입니다. 이용자가 자기 화면에서 접거나 숨긴 것은 그 기기에 저장되고, 관리자의 값으로 덮어쓰지 않습니다.
- 값은 요약 응답의 `settings`로 내려갑니다. 클라이언트는 다음에 요약을 받을 때부터 새 값을 씁니다. 갱신 간격은 클라이언트가 한 번 더 5~300초 안으로 맞춥니다 (서버의 값이 잘못되어도 너무 자주 묻지 않도록).
- **관리자 화면은 이용자의 금융 정보를 읽지 않습니다.** 잔액, 거래 내역, 순자산 어느 것도 나오지 않습니다 (테스트가 확인).
- DB 변경은 없습니다. 값은 v8.0의 `game_config`에 `dashboard` 키로 저장되고, 저장된 값이 없으면 기본값을 씁니다.

## 8. 성능과 접근성

| 지시서 11장 | 한 것 |
|---|---|
| 프레임레이트 영향 최소화 | 대시보드 전체와 축약 지도를 각각 **자기 캔버스**에 두어, 카드가 움직여도 나머지 HUD 를 다시 그리지 않음. 카드의 글자는 **데이터나 상태가 바뀔 때만** 다시 씀. 연결 상태 줄은 1초에 한 번. 다른 HUD 의 자리 재기는 0.25초에 한 번. 움직임이 끝나면 아무것도 고치지 않음 |
| UI 오브젝트 재사용 | 카드와 줄(row)을 처음에 한 번 만들고 값만 바꿈. 접고 펴거나 숨겨도 만들고 지우지 않음. 축약 지도의 메시는 색이 바뀔 때만 다시 만듦 |
| 불필요한 API 요청 제한 | 요약 하나로 세 카드. 기본 20초 간격, 사건이 있어도 2초에 한 번까지, 실패하면 물러남. 10분 동안 30번 (테스트가 확인) |
| 카드 애니메이션 최적화 | 0.18초의 감속 움직임. 자리·크기·투명도만 바꿈 (레이아웃 재계산 없음). 프레임이 끊겨도 목표를 지나치지 않음 |
| 키보드와 마우스 | F6~F9 와 Shift / Ctrl 조합. 왼쪽 Alt 를 누르고 있으면 커서가 풀려 카드를 누를 수 있음 ([HUD_LAYOUT_SYSTEM](HUD_LAYOUT_SYSTEM.md) 5장) |
| 색 말고도 모양과 글자로 | 위험 단계: `● 안전` `▲ 주의` `◆ 위험` `■ 긴급`. 늘고 줄어든 금액: `▲ +1,200 GC` `▼ −300 GC`. 연결 상태: `●` `▲` `…`. 침공: `■`와 글자. 꼬리표: "개발용 샘플", "준비 중" |
| 글자 크기와 UI 배율 | 80 / 100 / 120 / 140% (대시보드 설정). 카드 안의 글자와 그림이 함께 커짐 |

말투는 게임의 다른 화면과 같이 초등학생이 읽을 수 있게 썼습니다 ("전투가 끝나면 자세히 볼 수 있어요").

## 10. 한계와 남은 일

- **Unity 에서 실행해 보지 못했습니다.** 카드의 모양(반투명 유리, 둥근 모서리, 그림자), 글자 크기, 움직임, 다른 HUD 와의 간격을 눈으로 본 적이 없습니다. 자리 잡기는 계산으로만 확인했습니다.
- **게임과 서버가 이어져 있지 않습니다** (v8.0부터의 문제). 게임은 모의 서버의 요약을 받습니다. 실제 서버의 요약은 서버 테스트와 로컬 HTTP 확인으로, 형식은 표본으로 대조했습니다.
- 서버에 은행·가상 주식·대출이 없습니다. 실제 서버에서는 계좌 카드의 여섯 줄 가운데 **보유 GC 와 순자산(=보유 GC)만 실제 값**입니다 ([FINANCE_DASHBOARD](FINANCE_DASHBOARD.md) 3장).
- 실시간으로 밀어 주는 통로가 없어 다른 사람이 바꾼 값은 다음 주기(기본 20초)에 보입니다.
- 가상 주식 시세 갱신은 주식 기능이 생기면 같은 요약에 실으면 됩니다. 지금은 자리만 있습니다.
- 카드의 자리를 끌어서 옮기는 기능은 없습니다. 타워디펜스에서 오른쪽 / 왼쪽을 고르는 것까지입니다.
- 키를 바꾸는 화면이 없습니다 (게임 전체에 키 설정 화면이 아직 없음). F6~F9 는 고정입니다.
- Android · iOS: 자리 잡기는 화면 크기에 맞춰지지만, 터치 조작(누르기, 쓸어 넘기기)과 작은 화면에서의 크기는 만들지 않았습니다.
- 알림의 기록 화면, 소리, 다시 보기가 없습니다.
