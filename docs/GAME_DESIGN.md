# GAME_DESIGN — 게임 디자인

> 기준 v6.0 (PROJECT ZERO) · 2026-11-13 · 상태: 설계 (미구현) · 수치는 플레이테스트로 조정할 초기값

## 1. 한 줄 설명

내 방에서 나와 도시의 폭주 로봇을 물리치고, 번 돈으로 장비를 사고 저축하며, 이웃과 함께 우리 도시를 지키는 3D 도시 생활 RPG.

## 2. 디자인 기둥

| 기둥 | 뜻 | 판단 기준 |
|---|---|---|
| 재미 먼저 | 기능 수보다 "한 번 더" 하고 싶은 느낌 | 새 기능이 30초 안에 즐거움을 주지 못하면 뒤로 미룬다 |
| 설명 없이 시작 | 초등학생이 글을 읽지 않아도 진행 | 첫 10분 동안 메뉴 화면 0개, 목표 표시는 항상 1개 |
| 살아 있는 도시 | 접속자가 적어도 도시가 움직인다 | 광장에 항상 움직이는 NPC가 보인다 |
| 정직한 경제 | 돈의 흐름을 직접 겪으며 배운다 | 모든 거래는 서버 원장에 남고, 현실 결제와 연결되지 않는다 |
| 하나의 캐릭터 | 생활·전투·방어·금융이 같은 캐릭터와 자산을 공유 | 모드가 바뀌어도 장비와 GC가 그대로다 |

## 3. 핵심 루프

```
생활(내 방) → 탐험(도시) → 전투(로봇 사냥) → 수익(GC·경험치)
     ↑                                              ↓
도시 방어(타워디펜스) ← 성장(레벨·장비·도시) ← 소비·투자(상점·은행)
```

- 짧은 루프 (1~3분): 로봇 발견 → 전투 → GC 획득
- 중간 루프 (10~20분): GC 모으기 → 무기 구매·장착 → 더 강한 구역 또는 방어전
- 긴 루프 (며칠): 저축·투자로 자산 불리기 → 방 꾸미기 → 도시 레벨과 랭킹 올리기

## 4. 첫 10분

1. 내 방에서 눈을 뜬다. 화면에는 캐릭터와 방만 있다.
2. WASD로 움직이면 컴퓨터가 빨갛게 깜빡이며 침공 경고를 띄운다.
3. 밖에서 주민의 구조 요청이 들린다. 문이 빛난다.
4. 문을 나서면 도시. 오작동 로봇 한 대가 주민을 위협한다.
5. 좌클릭으로 로봇을 쓰러뜨린다. GC가 튀어나와 지갑으로 들어온다.
6. 주민이 고마워하며 상점을 가리킨다. 번 돈으로 살 수 있는 무기가 보인다.
7. 방어대장이 전입신고를 권한다. 거절해도 계속 놀 수 있다.

상세 단계와 화면은 [USER_FLOW](USER_FLOW.md)에 있습니다.

## 5. 시스템 구성

| 시스템 | 플레이어가 하는 일 | 문서 | 1차 포함 |
|---|---|---|---|
| 개인 방 | 시작, 휴식, 꾸미기, 컴퓨터로 금융·지도 이용 | ROOM_SYSTEM | 기본 가구만 |
| 캐릭터 | 이동, 점프, 공격, 꾸미기 | CHARACTER_SYSTEM | 자동 생성, 기본 동작 |
| 3D 도시 | 탐험, NPC 만나기, 시설 이용 | MAP_SYSTEM | 대표 도시 1곳 |
| 전투 | 로봇 사냥 | COMBAT_SYSTEM | 무기 2종, 적 2종 |
| 타워디펜스 | 타워 설치와 직접 전투로 도시 방어 | TOWER_DEFENSE | 타워 2종, 스테이지 1개 |
| 전입신고 | 도시 주민 되기 | RESIDENCY_SYSTEM | 포함 |
| 아이템·상점 | 구매, 장착, 사용 | ITEM_SYSTEM | 무기·회복 아이템 |
| 은행 | 입출금, 저축, 이자 | ECONOMY_SYSTEM | 보통예금 |
| 주식 | 가상 기업 투자 | STOCK_SYSTEM | DB·API 설계만 |
| 대출·신용 | 대출, 상환, 신용점수 | LOAN_CREDIT_SYSTEM | DB·API 설계만 |
| 커뮤니티 | 채팅, 친구, 파티 | COMMUNITY_SYSTEM | DB·API 설계만 |

## 6. 성장

| 축 | 방법 | 효과 |
|---|---|---|
| 캐릭터 레벨 | 전투 경험치 | 최대 체력 증가, 상위 장비·구역·기능 해금 |
| 장비 | 상점 구매, 드롭 | 공격력, 방어력 |
| 타워 | GC로 영구 강화 | 방어전 난이도 완화 |
| 자산 | 저축, 투자 | 더 비싼 장비와 가구 |
| 방 | 가구 구매 | 꾸미기, 표현 |
| 도시 | 주민들의 방어 기여 | 도시 레벨, 랭킹, 공동 시설 |

기능 해금은 레벨로 천천히 엽니다. 처음에는 전투와 상점만 보이고, 은행(레벨 3), 주식(레벨 8), 대출(레벨 10)은 NPC가 차례로 소개합니다. 해금 레벨은 관리자에서 바꿀 수 있습니다.

## 7. 실패와 불이익

어린 이용자가 좌절하지 않도록 실패의 대가를 작게 둡니다.

- 전투에서 쓰러지면 가까운 안전 지점(광장 또는 내 방)에서 다시 일어납니다. GC와 아이템은 잃지 않습니다.
- 방어전에서 지면 보상의 일부(참가 보상)만 받고 다시 도전할 수 있습니다.
- 주식 손실과 대출 연체는 실제로 일어나지만 한도와 보호 장치가 있습니다 (STOCK_SYSTEM, LOAN_CREDIT_SYSTEM).

## 9. 1차 플레이 가능 버전 범위

지시서 23장의 17단계가 Windows에서 끊기지 않고 이어지는 것이 완료 기준입니다. 점검표는 [TEST_PLAN](TEST_PLAN.md) 3장에 있습니다.

1차에서 만들지 않는 것: 주식·대출·신용점수의 게임 내 화면, 실시간 채팅, 친구·파티, 캐릭터 꾸미기 화면, 가구 구매, 대표 도시 외의 3D 도시, 보안 드론 이후의 적, 추후 타워 3종, 모바일 빌드. 다만 이들을 위한 DB 테이블과 API 경로는 처음부터 자리를 잡아 둡니다.

## 10. 이용자 보호 원칙

- 현실 결제로 GC를 사거나 대출을 갚는 기능을 만들지 않습니다.
- 투자와 대출을 권유하는 반복 알림을 보내지 않습니다.
- 채팅은 정해진 문구만 쓰는 제한형부터 시작합니다.
- 실제 주소, 위치, 학교 이름을 수집하지 않습니다. 전입신고의 도시는 실제 거주지와 무관합니다.
- 적은 기계이고 "정지"됩니다. 피와 잔혹한 표현을 쓰지 않습니다.
