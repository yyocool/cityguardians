# EQUIPMENT_SYSTEM — 전투 장비

> 기준 v8.0 · 2026-11-13 · 상태: 장비 8종의 구매·강화·모드별 장착을 규칙, 모의 서버, PHP 서버, 관리자 화면에 구현. Unity 화면은 실행해 보지 못함 · 가격과 성능은 초기값

## 1. 방향

전투로 번 GC를 다음 전투의 준비에 씁니다. 다만 **비싼 장비가 승리를 보장하면 안 됩니다.** 장비는 싸우는 방법을 넓혀 주는 것이고, 이기고 지는 것은 위치와 판단이 정해야 합니다.

| 원칙 | 구현 |
|---|---|
| 무료 기본 장비로 모든 핵심 전투에 참여 | 디펜스는 기관총 타워, 헌트는 스파크 배턴, FPS는 에너지 블래스터와 회복 장치가 처음부터 무료. 관리자 화면은 무료 기관총 타워와 FPS의 무료 기본 장비를 없애는 변경(값을 매기기, 해금 레벨 올리기, 끄기)을 거부합니다 |
| 장비는 GC로만 | 현금 결제 기능이 없습니다. GC는 현실 화폐와 바꿀 수 없습니다 |
| 강화 효과는 작게 | 한 단계에 10%, 최대 3단계(20%). 가장 비싼 장비도 무료 장비의 몇 배로 강하지 않습니다 |
| 장비마다 역할이 다르게 | 비싼 장비는 "더 센 것"이 아니라 "다른 것"입니다 (정밀 라이플은 한 발이 세지만 느리고 탄창이 작습니다) |
| 모드마다 따로 사지 않음 | 장비는 플레이어당 한 번만 저장합니다. 어느 모드의 어느 칸에 꼈는지만 따로 적습니다 |
| 개인 자산과 도시 자산을 구분 | 5장 |

## 2. 장비의 종류

"장비"라는 말이 세 곳에서 쓰입니다. 저장하는 곳이 서로 다릅니다.

| 무엇 | 쓰는 모드 | 문서 | 저장 |
|---|---|---|---|
| 무기·방어구·옷 (스파크 배턴, 볼트 블래스터, 가디언 헬멧 …) | 헌트, 디펜스 (캐릭터가 직접 싸울 때) | [ITEM_SYSTEM](ITEM_SYSTEM.md) | 가방 (v6.0, 클라이언트 모의 서버에만 있음) |
| 타워와 방어시설 15종 | 디펜스 | [DEFENSE_MODE](DEFENSE_MODE.md) 3장 | `defense_structures`, `player_defense_structures`, `city_defense_structures` |
| **전투 장비 8종** | FPS | 이 문서 | `combat_equipment`, `player_combat_equipment`, `combat_loadouts`, `equipment_upgrades` |

전투 장비의 정의에는 "쓸 수 있는 전투 모드" 목록(`modes`)이 있습니다. 지금은 8종 모두 FPS 전용이지만, 같은 장비를 헌트 모드에서도 쓰게 하려면 목록에 모드를 더하면 됩니다. 장착 칸은 모드마다 따로 있습니다.

## 3. 전투 장비 8종

칸은 셋입니다: **주 무기**(마우스 왼쪽), **보조 장치**(Q), **지원 장비**(F).

### 주 무기

| | 에너지 블래스터 | 정밀 에너지 라이플 | 충격파 발사기 |
|---|---|---|---|
| 가격 | **무료** (처음부터 보유) | 600 GC | 800 GC |
| 해금 레벨 | 1 | 4 | 5 |
| 공격력 | 12 | 55 | 30 |
| 초당 공격 | 5 | 1.2 | 0.8 |
| 사거리 | 30 m | 60 m | 7 m, 정면 60도 |
| 탄창 / 재장전 | 24발 / 1.4초 | 6발 / 1.8초 | 4발 / 2초 |
| 조준 시야 | 0.8배 | 0.45배 (크게 당겨 봄) | 0.9배 |
| 특징 | 빠르게 쏘는 기본 무기 | 멀리 있는 단단한 로봇 | 가까운 로봇 여럿을 밀어냄 |
| 강화 기본 비용 | 150 GC | 300 GC | 350 GC |

초당 피해로 보면 블래스터 60, 라이플 66, 충격파 24(여럿에게)입니다. 유료 무기가 무료 무기보다 압도적으로 세지 않습니다.

### 보조 장치 (Q)

| | 회복 장치 | EMP 장치 | 보호막 |
|---|---|---|---|
| 가격 | **무료** | 500 GC | 700 GC |
| 해금 레벨 | 1 | 3 | 5 |
| 효과 | 체력 40 회복 | 7 m 안의 로봇을 3초 멈춤 | 6초 동안 피해 60까지 막음 |
| 재사용 대기 | 30초 | 20초 | 25초 |
| 강화 기본 비용 | 120 GC | 250 GC | 300 GC |

### 지원 장비 (F)

| | 탐지 센서 | 지원 드론 |
|---|---|---|
| 가격 | 300 GC | 1,200 GC |
| 해금 레벨 | 2 | 6 |
| 효과 | 8초 동안 45 m 안의 로봇 위치를 벽 너머로 보여 줌 | 15초 동안 따라다니며 가까운 로봇을 쏨 (피해 8, 초당 2발, 14 m) |
| 재사용 대기 | 15초 | 40초 |
| 최대 강화 | 2단계 | 3단계 |
| 강화 기본 비용 | 200 GC | 400 GC |

지원 장비 칸에는 무료 기본 장비가 없습니다. 비워 둔 채로 임무에 나설 수 있습니다.

## 4. 구매, 강화, 장착

### 구매

- 조건: 준비 중이 아님, 아직 없음, 레벨이 해금 레벨 이상, GC가 충분함.
- 값은 서버가 장비 정의에서 읽습니다. 요청에 가격을 넣어도 무시합니다.
- 원장 사유는 `gear_purchase`. `Idempotency-Key`가 필수이고 같은 키로 다시 보내면 처음 응답을 돌려줍니다.

### 강화

```
강화 비용 = 강화 기본 비용 × 지금 단계
공격력 · 효과 값 = 기본값 × (100 + 10 × (단계 − 1)) / 100
재사용 대기     = 기본값 × (100 − 10 × (단계 − 1)) / 100
```

- 에너지 블래스터: 1→2단계 150 GC, 2→3단계 300 GC. 3단계의 공격력은 12 → 14.
- 무료 기본 장비도 강화할 수 있습니다 (사지 않아도 1단계로 가진 것으로 봅니다).
- 강화할 때마다 `equipment_upgrades`에 한 줄이 남습니다 (언제, 몇 단계에서 몇 단계로, 얼마에). 원장 사유는 `gear_upgrade`.
- 무기는 공격력이, 장치는 효과 값(회복량, 보호막의 양, 드론의 피해)과 재사용 대기가 좋아집니다. 사거리·탄창·연사 속도·지속 시간·범위는 강화로 바뀌지 않습니다.
- 재사용 대기가 줄어드는 것은 클라이언트의 규칙(`GearRules.Cooldown`)에 있습니다. 서버는 장치를 언제 썼는지 검증하지 않습니다.

### 장착

- `PUT /combat/loadouts`에 모드, 칸, 장비 코드를 보냅니다. 장비 코드를 비우면 그 칸을 기본으로 되돌립니다.
- 서버가 확인하는 것: 그 모드에서 쓸 수 있는 장비인가, 그 칸에 끼는 장비인가, 가지고 있는가.
- 고른 적이 없거나 고른 장비를 더는 쓸 수 없으면 그 칸의 무료 기본 장비가 장착된 것으로 봅니다. 그래서 **장착을 한 번도 하지 않은 플레이어도 바로 임무에 나설 수 있습니다.**

### 유지 비용

장비와 타워의 정의에 유지 비용(`upkeep_gc`) 칸이 있고 관리자에서 값을 넣을 수 있습니다. **지금은 값만 저장하고 걷지 않습니다.** 모든 초기값이 0입니다. 유지 비용을 걷으려면 "언제, 무엇에서, 못 내면 어떻게 되는가"를 먼저 정해야 하고, 못 냈다고 장비를 잃거나 빚이 생기게 하지 않는다는 원칙([COMBAT_ECONOMY](COMBAT_ECONOMY.md) 5장) 안에서 설계해야 합니다.

## 5. 개인 자산과 도시 자산

| | 개인 자산 | 도시 자산 |
|---|---|---|
| 무엇 | 전투 장비, 영구 해금한 타워(폭발·레이저·감속·EMP 타워) | 도시 공용 방어시설 (에너지 방어막, 지휘 센터, 긴급 방어 지원 장치) |
| 누구의 것 | 산 플레이어 | 도시. 주민 누구의 것도 아님 |
| 얻는 법 | GC로 구매·해금 | 주민들이 기금을 모아 완성 |
| 저장 | `player_combat_equipment`, `player_defense_structures` | `city_defense_structures` (도시별 기금 누적) |
| 이사하면 | 그대로 가짐 | 도시에 남음 |
| 되찾기 | — | 낸 기금은 돌려받지 않음 |
| 효과 | 내 전투 | 도시의 방어력 (NPC 수비대가 침공을 막을 확률), 완성될 때 위험도가 내려감 |

기금에 대해서는 [CITY_RISK_SYSTEM](CITY_RISK_SYSTEM.md) 9장에 있습니다.

## 6. 화면

방어기지의 출동 게이트 옆 **작전 단말기**에서 "전투 장비"를 고릅니다. 장비마다 가진 여부, 단계, 가격 또는 강화 비용, 살 수 없는 이유(레벨·GC)가 보이고, 숫자 키로 사고·강화하고·장착합니다. "기본 장비만으로도 임무를 끝낼 수 있어요"라는 안내가 함께 나옵니다.

구현: `EquipmentSystem`(`Gameplay/Combat/CombatServices.cs`), `GearRules`(`Domain/Combat.cs`), `FpsWeapon`(장착한 장비를 읽어 동작).

## 7. 서버

| 항목 | 내용 |
|---|---|
| 규칙 | `server/src/Domain/Gear.php`. C#의 `GearRules`와 같은 결과를 내는지 표본으로 확인 |
| 서비스 | `CombatService::equipment / buy / upgrade / equip` |
| API | `GET /combat/equipment`, `POST /combat/equipment/{code}/purchase`, `POST /combat/equipment/{code}/upgrade`, `PUT /combat/loadouts` ([API_SPEC](API_SPEC.md) 14장) |
| 오류 | 레벨 부족·준비 중은 `LOCKED`, GC 부족은 `INSUFFICIENT_GC`, 이미 가짐·더 강화할 수 없음은 `CONFLICT`, 없는 장비는 `NOT_FOUND`, 낄 수 없는 장비는 `VALIDATION_FAILED`. 자세한 이유는 `reason`에 (`level_too_low`, `not_owned`, `wrong_slot` …) |
| 관리자 | "전투 장비"(이름, 해금 레벨, 준비 중, 사용 여부)와 "장비 가격 및 성능"(가격, 강화, 수치). 장비를 더하거나 지우는 기능은 없고 고치기만 합니다 |
