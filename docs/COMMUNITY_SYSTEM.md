# COMMUNITY_SYSTEM — 채팅과 커뮤니티

> 기준 v6.0 · 2026-11-13 · 상태: 설계 (Phase 5 구현, 1차에서는 DB·API 자리만 준비) · 수치는 초기값

## 1. 방향

같은 도시의 주민끼리 인사하고, 함께 싸울 사람을 찾을 수 있어야 합니다. 다만 초등학생이 이용하는 공간이므로 **안전이 기능보다 먼저**입니다. 안전한 범위에서 시작해 운영 준비가 되는 만큼 넓힙니다.

## 2. 기능

| 기능 | 내용 | 시점 |
|---|---|---|
| 도시 공지 | 운영자·도시 소식 (읽기 전용) | Phase 5 초기 |
| 이모티콘, 감정 표현 | 캐릭터 머리 위 표시 | Phase 5 초기 |
| 지역 채팅 | 같은 도시 주민 채널 | Phase 5 (제한형부터) |
| 친구 추가, 친구 목록 | 요청 → 수락 | Phase 5 |
| 파티 | 최대 4명, 함께 방어전 | Phase 5 (협동 전투는 실시간 전투 서버 필요) |
| 파티 채팅 | 파티원 채널 | Phase 5 |
| 신고 | 메시지, 닉네임, 행동 | 채팅과 동시에 |
| 차단 | 상대의 채팅·요청·초대가 보이지 않음 | 채팅과 동시에 |

신고와 차단이 준비되지 않으면 채팅을 열지 않습니다.

## 3. 채팅 방식

| 단계 | 방식 | 내용 |
|---|---|---|
| 0 | 꺼짐 | 채팅 없음. 공지와 이모티콘만 |
| 1 | 제한형 | 미리 정한 문구와 이모티콘만 보낼 수 있음 ("같이 방어전 가요!", "고마워요", "도와주세요") |
| 2 | 필터형 자유 채팅 | 직접 입력. 욕설·개인정보 필터를 거침 |

- **기본은 1단계(제한형)입니다.** 누구에게나 안전하고 운영 인력 없이도 유지할 수 있습니다.
- 2단계는 연령별 정책, 신고 처리 인력, 제재 절차가 준비된 뒤 관리자에서 켭니다.
- **나이를 확인하지 않은 이용자는 미성년자로 봅니다.** 게스트는 나이 정보가 없으므로 항상 가장 제한된 단계가 적용됩니다.
- 채널별·연령대별 허용 단계는 `chat_policies`에 두고 관리자에서 바꿉니다.

제한형 문구는 상황별 묶음(인사, 전투, 감사, 요청)으로 제공하고 관리자에서 추가합니다.

## 4. 구조

```
Unity 클라이언트
   │  ① 채팅 입장권 요청 (HTTPS)
   ▼
PHP API ──── MySQL (계정, 친구, 차단, 정책, 신고, 제재)
   │  ② 짧은 수명의 입장권 발급
   ▼
Unity 클라이언트
   │  ③ 입장권으로 접속 (WebSocket, wss)
   ▼
실시간 서비스 (별도 프로세스)
   ├─ 채널 관리: 지역, 파티
   ├─ 메시지 검사: 정책, 필터, 속도 제한
   ├─ 차단 반영
   └─ 메시지 보관 (정해진 기간)
```

| 구성 | 역할 |
|---|---|
| PHP / MySQL | 계정, 친구, 차단, 채팅 정책, 신고, 제재의 원본. 입장권 발급 |
| 실시간 서비스 | 접속 유지, 메시지 중계, 실시간 검사. 정책과 제재 상태는 PHP 쪽에서 받아 적용 |

- 실시간 서비스는 PHP와 **별도 프로세스**로 둡니다. 나중에 멀티플레이 전투를 위한 실시간 서버로 넓히거나 다른 서버로 옮길 수 있습니다.
- 기술 후보는 Node.js 기반 WebSocket 서버입니다. 운영 서버에 새 프로세스를 띄우고 웹 서버에 WebSocket 중계 설정을 추가해야 하므로 **서버 변경 승인이 필요합니다** ([SERVER_DEPLOYMENT](SERVER_DEPLOYMENT.md) 7장).
- 입장권은 한 번만 쓸 수 있고 수명이 짧습니다(초기값 60초). 게임 접속 토큰을 실시간 서비스에 직접 보내지 않습니다.
- 클라이언트는 `IRealtimeClient` 인터페이스 뒤에 두어 서비스 구현이 바뀌어도 게임 코드를 고치지 않게 합니다.

1차 버전에는 실시간 서비스가 없습니다.

## 5. 안전 장치

### 5.1 욕설 필터

- 금칙어 목록(`banned_words`)을 관리자에서 관리합니다.
- 글자 사이에 기호나 공백을 넣는 변형, 초성만 쓰는 변형을 정규화한 뒤 검사합니다.
- 걸린 메시지는 보내지지 않고, 보낸 사람에게 "이 말은 보낼 수 없어요"라고 알려 줍니다.
- 닉네임에도 같은 필터를 씁니다.

### 5.2 개인정보 노출 방지

자유 채팅에서 다음 형태를 찾아 막습니다.

- 전화번호, 주민등록번호로 보이는 숫자열
- 이메일, 웹 주소, 메신저·SNS 아이디를 묻거나 알려 주는 표현
- 주소, 학교 이름, 나이를 묻는 표현

막을 때는 이유를 알려 줍니다: "전화번호나 사는 곳은 알려 주지 않아요." 제한형 채팅에서는 이런 내용을 보낼 방법이 없습니다.

### 5.3 속도 제한

같은 말 반복, 짧은 시간의 연속 전송을 제한합니다 (초기값: 3초에 1건, 같은 문장 연속 2회까지).

### 5.4 신고

1. 메시지나 캐릭터를 눌러 "신고" → 이유 선택 (욕설, 괴롭힘, 개인정보 요구, 기타).
2. 서버가 신고 대상 메시지와 앞뒤 대화를 증거로 묶어 저장합니다.
3. 신고한 사람에게는 상대가 바로 차단됩니다.
4. 관리자의 "채팅 신고" 메뉴에 올라가고, 담당자가 확인해 제재를 결정합니다.
5. 짧은 시간에 여러 사람에게 신고된 이용자는 담당자 확인 전까지 채팅이 일시 정지됩니다 (초기값: 1시간 내 서로 다른 3명).

허위 신고의 반복도 제재 대상입니다.

### 5.5 차단

차단하면 상대의 채팅, 친구 요청, 파티 초대가 보이지 않습니다. 상대에게는 차단 사실을 알리지 않습니다. 차단 목록은 서버에 저장되어 기기를 바꿔도 유지됩니다.

### 5.6 제재

| 제재 | 내용 |
|---|---|
| 경고 | 안내 메시지 |
| 채팅 정지 | 기간 동안 채팅 불가 (제한형 포함 여부 선택) |
| 이용 정지 | 기간 동안 접속 불가 |
| 닉네임 강제 변경 | 부적절한 닉네임 |

제재는 관리자가 사유와 기간을 적어 부과하고, 대상자에게 사유를 알려 줍니다. 모든 제재는 기록에 남습니다.

### 5.7 이용 제한

| 항목 | 내용 |
|---|---|
| 채팅 권한 | 주민만 지역 채팅 이용. 이방인은 읽기도 불가 |
| 친구 요청 | 하루 요청 수 제한. 요청 받지 않기 설정 |
| 귓속말(1:1 대화) | 제공하지 않음. 낯선 사람과의 비공개 대화 통로를 만들지 않기 위함. 친구 사이 대화는 자유 채팅 정책과 함께 추후 검토 |
| 채팅 끄기 | 설정에서 채팅 전체를 끌 수 있음 |

### 5.8 메시지 보관과 삭제

| 대상 | 보관 (초기값) |
|---|---|
| 일반 채팅 메시지 | 30일 뒤 삭제 |
| 신고된 메시지와 증거 | 처리 완료 후 90일 뒤 삭제 |
| 제재 기록 | 계정이 유지되는 동안 |

보관 기간은 법적 요건을 확인한 뒤 확정합니다 ([SECURITY_POLICY](SECURITY_POLICY.md) 9장). 삭제는 예약 작업이 자동으로 수행합니다.

## 6. 친구와 파티

### 친구

- 요청 → 수락으로 맺습니다. 최대 50명.
- 친구 목록에는 닉네임, 도시, 접속 여부만 보입니다.
- 친구를 끊거나 차단하면 상대에게 알리지 않습니다.

### 파티

- 최대 4명. 친구 또는 같은 도시 주민을 초대합니다.
- 파티 채팅은 지역 채팅과 같은 정책 단계를 따릅니다.
- 파티 단위 협동 방어전은 실시간 전투 서버가 필요하므로 그 전까지는 "같은 스테이지를 각자 깨고 기여도를 합산"하는 방식으로 시작합니다.

## 7. 데이터와 API

| 테이블 | 내용 |
|---|---|
| `friendships` | 친구 관계와 요청 상태 |
| `blocks` | 차단 |
| `reports` | 신고, 증거, 처리 상태 |
| `sanctions` | 제재 |
| `chat_policies` | 채널·연령대별 채팅 단계, 속도 제한 |
| `chat_phrases` | 제한형 채팅 문구 |
| `banned_words` | 금칙어 |
| `chat_messages` | 메시지 보관 (기간 한정) |
| `parties`, `party_members` | 파티 |
| `city_notices` | 도시 공지 |

| API | 용도 |
|---|---|
| `GET /friends`, `POST /friends`, `PUT /friends/{id}`, `DELETE /friends/{id}` | 친구 목록, 요청, 수락·거절, 삭제 |
| `GET /blocks`, `POST /blocks`, `DELETE /blocks/{id}` | 차단 |
| `POST /reports` | 신고 |
| `GET /chat/policy` | 내게 적용되는 채팅 단계, 문구 목록 |
| `POST /chat/ticket` | 실시간 서비스 입장권 |
| `GET /notices/city` | 도시 공지 |

1차 버전에서는 `friendships`, `blocks`, `reports`, `sanctions`, `chat_policies` 테이블을 만들어 두고 API는 구현하지 않습니다.
